# 🎓 智慧教务管理系统 (Smart Academic System)

一个基于 Spring Boot + MyBatis 开发的现代化教务管理系统。采用前后端分离的设计思想，实现了学生、教师两大角色的高效协同，包含选课、排课、成绩管理等核心教务功能。

## 🛠️ 技术栈

*   **后端**：Java 17, Spring Boot 4.x, Spring Security, JWT (鉴权), MyBatis, MySQL 8.0
*   **前端**：原生 HTML5, CSS3, JavaScript (ES6), Fetch API
*   **架构模式**：RESTful API 设计，基于 iframe 的 SPA (单页应用) 体验

## ✨ 核心功能

### 🔐 统一认证中心
*   **单点登录**：学生、教师共用一个登录入口，系统自动根据账号角色（STUDENT / TEACHER）跳转对应工作台。
*   **安全防护**：集成图形验证码拦截恶意登录；基于 JWT 的无状态会话控制，保障接口安全。

### 🎓 学生端
*   **选课中心**：支持查看所有可选课程，进行选课与退课，实时显示课程容量与已选人数，并带有防重复选课校验。
*   **我的课表**：以 7x6 二维网格视图直观展示每周排课，自动计算总学分与本周课时。
*   **成绩查询**：查看各科成绩，自动计算已获学分、最高分及平均分，并标注及格/不及格状态。
*   **个人信息**：展示学号、姓名、班级等基本信息。

### 👨‍🏫 教师端
*   **我的课程**：卡片式展示教师名下课程，直观的进度条展示满员情况。
*   **课表查看**：按网格查看自己的授课时间与教室安排。
*   **学生名单管理**：查看选修自己课程的学生列表，支持一键将学生**移出课程**（仅解除该教师名下的选课与成绩关联，不破坏学生账号）。
*   **成绩录入**：直接在表格中为学生在线打分并实时保存，自动判断成绩有效性。

## 💡 技术亮点

1.  **现代化 SPA 架构**：巧妙使用 `iframe` 结合 CSS 样式，将传统的多页面跳转改造为“左侧导航固定 + 右侧内容无刷新切换”的 SPA 体验，极大地提升了系统的流畅度。
2.  **企业级 UI/UX 设计**：摒弃传统教学项目的简陋界面，采用类似 Ant Design / Dashboard 的卡片式布局、柔和阴影与渐变色，高度还原真实企业级后台。
3.  **严谨的业务逻辑**：
    *   使用 `@Transactional` 保证选课/退课、录入成绩等高并发场景下的数据一致性。
    *   “移出学生”接口实现了精准的级联解绑（遍历教师课程 -> 删成绩 -> 删选课记录 -> 人数减一），绝不误删学生账号。
4.  **全局异常处理与容错**：前后端统一拦截并处理异常，避免传统系统的 500 报错直接暴露给用户；前端全面加入 `res.ok` 校验与 Token 过期重定向机制。
5.  **深度联表查询**：通过 MyBatis 的 `LEFT JOIN` / `INNER JOIN` 高效实现多表数据聚合（如一次性查出课表所需的课程信息、教师姓名、教室地点等）。

## 🚀 快速启动

1.  **数据库准备**：在 MySQL 中创建数据库 `jwsystem`，并导入 `sql` 脚本（包含 user, course, course_selection, course_schedule, score 表）。
2.  **修改配置**：在 `application.yml` 中配置你的数据库账号和密码。
3.  **运行项目**：使用 IDEA 打开项目，运行 `JwsystemPublicApplication.java`。
4.  **访问系统**：浏览器打开 `http://localhost:8080/login.html`。
    *   *默认学生账号*：`2021001` / `123456`
    *   *默认教师账号*：`T001` / `123456`
